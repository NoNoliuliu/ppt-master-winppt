# ppt-master-winppt

原名 **win-ppt**，自 **2.0.1** 起统一更名为 `ppt-master-winppt`。下文 ZIP、1.0.2 和 2.0.0 的历史对比对应更名前版本，名称迁移不改变这些历史行为。

基于 [Hugo He / PPT Master](https://github.com/hugohe3/ppt-master) v6.6.0 的本地改编版，保留四套卫宁健康模板及个性化工作规则。

## 获取与安装

下载本仓库 ZIP 并解压，将 `skills/ppt-master-winppt` 整个文件夹放入所用 AI 工具支持的 Skill 目录，然后重新加载 Skill。也可克隆本仓库；运行时需使用 Skill 所在目录的绝对路径。

运行环境为 Python 3.10+，按 `skills/ppt-master-winppt/requirements.txt` 安装对应依赖。不同功能的额外依赖见其工作流说明。内置 `lib` 是历史 Windows CPython 3.13 依赖，不适用于其他平台或 Python 版本，不能代替全部新版依赖。

API 凭据通过进程环境变量提供，或用 `WIN_PPT_ENV_FILE` 指定本地配置文件。不要把实际配置或凭据提交到 GitHub。

## 保留的改编

- 四套模板：AI汇报、橘色、深蓝色、暖调大地色，保留Logo与背景。
- 默认复制导入，保留原文件。
- 沿用明确的模板选择；设计确认后连续逐页执行，避免重复询问。
- 允许必要的图片检查；每页读取锁定设计规范。
- 完整本地规则见 [win-local.md](skills/ppt-master-winppt/references/win-local.md)。

## 版本关系与对比口径

本文区分两个“原版”：**原版 ZIP**指升级前的公司 ppt-master-winppt 分发包；**上游原版**指 Hugo He 的 PPT Master v6.6.0。两者不是同一个版本。

版本关系为：公司原版 ZIP → 本地 ppt-master-winppt 1.0.2（规则修正）→ ppt-master-winppt 2.0.0（合入上游 v6.6.0 并保留本地改编）→ 本仓库分享整理版。本地版本号与上游版本号独立。公司 ZIP 对应的确切上游祖先提交未知，不作完整 Git 三方合并的声明。

## 本地 1.0.2 新增了什么

以公司 ZIP 为比较基准，1.0.2 仅修改 `SKILL.md`、`references/executor-base.md` 和 `references/strategist.md` 三个文档；其余 4717 个实质文件一致，没有修改模板、图片或生成脚本。

| 本地修正 | 具体行为 |
|---|---|
| 保护源文件 | 将强制 `--move` 改为明确 `--copy`；生成 PPT 不意味着允许移动原文件 |
| 明确批准点 | 只保留模板选择和八项设计确认两个用户批准点；其他检查点作为内部核验或进度告知 |
| 复用已确认选择 | 已明确的模板及设计决定直接沿用，不重复询问 |
| 确认后连续执行 | 设计文档和执行参数清单不再单独等待批准；实质偏离已确认设计时才重新确认 |
| 允许视觉检查 | 可以查看必要图片，核验 Logo、文字、布局和最终效果 |
| 适配宿主工具 | 指定工具不可用时使用等效能力，但不能跳过必要批准 |

此外增加了 `1.0.2` 版本标识，并修正残留的“默认自由设计”前置条件，使其与明确选模板的流程一致。上述行为已迁移到 2.0.0 的本地规则中；原八项设计选择纳入新版第二阶段确认。

| 源文件处理 | 根据导入来源和参数决定复制或移动 | 兼容命令默认复制，显式要求才移动 |

| 环境配置 | 上游多位置配置查找机制 | 进程环境优先；显式 `WIN_PPT_ENV_FILE`，否则项目/仓库根 `.env` 回退 |
| 更新机制 | 上游仓库更新工具 | 固定上游快照，禁用安装副本直接更新；维护者通过正式源发布同步 |

新版模板适配采用一张空母版和五个零槽位布局，画面对象保留在页面内。这是兼容迁移，并非将所有品牌元素重做成可复用母版。上游原生编辑、图片重建等独立路由保留各自约束；用户明确要求 Quick 时可使用该路由，不能把普通生成默认改为跳过确认。

本仓库中的 Obsidian 发布规则用于维护者的正式源管理，同事使用生成能力不需要接入维护者的个人仓库；更新时应获取新分享版本并自行保留本地配置。
